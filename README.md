# Player Performance Regression Project 🚀

A machine learning regression project designed to analyze player data and predict performance scores, featuring an interactive GUI.

## 📁 Files in the Repository
* **`Regression_Phase_2 with GUI.ipynb`**: The main Jupyter Notebook containing data exploration, feature engineering, model training, and the interactive GUI implementation.
* **`regression_df.csv`**: The cleaned dataset used for training and evaluating the regression model.

## 🛠️ Built With
* Python
* Pandas, NumPy
* Scikit-Learn / Machine Learning Libraries
* Jupyter Notebook
